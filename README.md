# Varbase AI Figma Base

A Drupal recipe that wires the Varbase AI Figma tools (design resolver, page builder,
pattern tools, site wiring, page review) into a working end-to-end configuration on the
Canvas AI orchestrator.

Initial import in progress — see the project's [issue queue](https://www.drupal.org/project/issues/varbase_ai_figma_base) for the initialization issue.
