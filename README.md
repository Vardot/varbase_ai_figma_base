# Varbase AI Figma Base

[![pipeline status](https://git.drupalcode.org/project/varbase_ai_figma_base/badges/1.0.x/pipeline.svg)](https://git.drupalcode.org/project/varbase_ai_figma_base/-/pipelines)
[![Varbase AI Figma Base](https://img.shields.io/badge/Varbase%20AI%20Figma%20Base-1.0.5-0d6efc?labelColor=001d38&style=flat-square)](https://git.drupalcode.org/project/varbase_ai_figma_base/-/pipelines?ref=1.0.5)

Base recipe wiring the general **ai_figma** engine + **varbase_ai_figma** (Bootstrap 5.3 / vartheme_bs5) customization, Context Control Center, and the targeted Figma AI Context items into a Varbase site.

## Documentation

Read the [Varbase AI Figma Base documentation](https://docs.varbase.vardot.com/developers/understanding-varbase/varbase-ai-recipes/varbase-ai-figma-base) on the Varbase docs site.

## Installation

```
composer require drupal/varbase_ai_figma_base:~1
drush recipe recipes/varbase_ai_figma_base
drush cr
```
